# Changelog

## 0.1.0 release candidate

- Synced the bundled clean-install defaults with the documented and code defaults.
- Reworked the settings landing page so common mutation/cross-pollination controls are visible first and advanced controls are progressive disclosure.
- Clarified first mutation, Save Seeds, naming, cancel behavior, cultivar selection, and registry terminology.
- Added player-facing compatibility policy and removed the universal plant-mod compatibility claim.
- Added Horticulture-owned RimTest smoke coverage for clean startup, UX discovery, gameplay, and release regressions.
- Added an allowlisted release-package builder, package verifier, RimTest workflow metadata, and reproducible release manifest output.
- Added release, beta-feedback, defaults, compatibility, performance, and RC testing documentation.

This is a release-candidate polish pass. New gameplay systems are out of scope for this candidate.
