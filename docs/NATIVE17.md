# Native 1.7 development candidate

This branch contains the first standalone .NET 10 implementation. The main
branch and tracked 1.6 release remain the legacy baseline. The About/LoadFolders
metadata at the root still describes that baseline; only the isolated test
package generated by the native runner declares 1.7.

- The new journal records completed player sowing, documented cultivar identity
  and positively placed primary harvest output. No inferred yield, personal
  expertise, or framework claims. Each subject keeps a bounded 64-event retry
  window; this is not unlimited historical deduplication.
- Named, visible registry records authorize trait disclosure. Historical detailed
  Knowledge Framework data is not imported; the old Horticulture legacy record
  shape is read-only for compatibility. Old-save migration remains unqualified.
- Native Widgets surfaces replace Canvas document chrome; earlier native settings
  layouts are a starting point. UI polish, accessibility, large-list behavior,
  settings parity and interactive evidence remain open.
- Progression: Agriculture uses optional reflection; actual compatible integration
  is unqualified, and normal sowing rules remain authoritative.
- The prior texture compositor is still present; no Waylith shader effect has
  been implemented or qualified yet.

Run the dependency-free journal rules:

```powershell
dotnet run --project DevTools/NativeRules.Tests/NativeRules.Tests.csproj -c Release
```

Run the isolated native fixture only after the player closes RimWorld:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File DevTools/Run-NativeQuicktest.ps1
```

The runner requires clean source, an absent Horticulture install, and an exact
performance loadout. It creates a unique temporary test-only mod folder, copies
the legacy content folders and the standalone 1.7 seed-pack definition into its versioned 1.7 package, verifies the
commit-stamped loaded assembly, uses a disposable save-data directory, and stops
only the owned process. No public release packaging or normal game launch is
supported by this runner. Results live in ignored DevTools/TestResults. The
fixture is compiled only with NativeFixture=true and must never ship.

The legacy release builder and Framework/Canvas-specific source probes target
1.6 and are not a native qualification mechanism. Use main for the existing
1.6 release. A separate 1.7 production package builder and migration tests are
still required.

## Waylith investigation

Inspected installed Core ShaderDefs/Shaders.Map.xml and
Shaders/Map/CutoutPlant.frag.glsl and PlantWindSway.vert.glsl. The native
plant pipeline uses ShaderDef, a wind-aware vertex program, material
uniforms and samplers in descriptor set 2, a 0.35 alpha cutoff, and a
per-plant seed carried in UV0.z for seasonal coloration. PlantVisualUtility
already passes the appropriate wind exposure colors and UVZ payload into
Printer_Plane. Do not repurpose those channels blindly.

The next isolated shader proof should retain vanilla wind and alpha/seasonal
behavior while adding controlled phenotype parameters, compare against the
existing CPU compositor, and only then introduce masks/procedural patterns.
Shader code, visual comparisons and batching are not yet implemented or
qualified. No Core shader files were changed.

## Experimental opaque phenotype shader

The separate test-only ShaderPrototype assets use a unique ShaderDef and
the installed Core PlantWindSway vertex stage, with Horticulture's own HSV,
contrast, brightness, saturation, tint, dullness and outline compositor.
Shader materials retain the source texture and UV transform. WindManager
registration must be explicit for non-vanilla shader identities. The cache is
bounded to 128 materials for the process lifetime; it does not evict materials
that remain in the engine's wind registry.

Activation is limited to the isolated native shader fixture. Seasonal sources,
translucency, other shaders, semantic/isolated mask layers and unavailable
layouts continue through the existing CPU path. No Core files are changed.
No new CPU readback is performed on the shader material path. The fixture
deliberately disables automatic masks on a disposable test crop to exercise
the whole-plant shader. It uses GPU swatches and a real field screenshot; GPU
readback in this fixture is explicitly for testing, not a draw-time behavior.
Run it separately, with the game closed:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File DevTools/Run-NativeQuicktest.ps1 -Loadout Minimal -ShaderProbe

Shader files are staged only for that switch. Ordinary gameplay candidates
remain on the existing renderer. Full seasonal/mask/produce/preview semantics,
artist controls, batching and performance remain unqualified.
